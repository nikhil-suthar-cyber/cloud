# DocuFlow Cloud

A modern document processing workspace built with **TanStack Start**, **React 19**, **Vite**, and **Tailwind CSS**.

## Features

- **Document Processing**: Upload and inspect PDF, TXT, CSV, and image documents.
- **Local Analysis**: Client-safe analysis reports with metadata extraction and local IndexedDB persistence.
- **Modern UI**: Built with Radix UI primitives and Tailwind CSS.
- **Full Type Safety**: End-to-end TypeScript support.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Development Server

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

To create a production build:

```bash
npm run build
```

### Testing

Run test suite:

```bash
npm test
```
